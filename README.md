# Chasse aux Bonbons : Pas de Quartier

**Grimpe ou crève les poches pleines**

Joue en ligne sur : [https://games.hylst.fr/chassebonbons/](https://games.hylst.fr/chassebonbons/)

## Description
Un jeu de plateforme verticale rétro d'Halloween où tu sautes de corniche en corniche, ramasses un maximum de friandises et évites les créatures de la nuit avant de rater une prise.

## Controles
| Contrôle | Action |
|---|---|
| Flèches / Q-D | Déplacement gauche/droite |
| Espace / Flèche haut | Saut |
| Tactile | Zones virtuelles gauche / droite / saut |

## Developpement
```bash
# Installer les dependances
npm install

# Lancer le serveur local
npm run dev

# Compiler pour la production (build single-file)
npm run build
```
